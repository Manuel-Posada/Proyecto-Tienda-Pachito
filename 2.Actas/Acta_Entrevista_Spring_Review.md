Durante la reunión se presentó al stakeholder el mockup del sistema web diseñado para la gestión de la tienda.<br><br>

El stakeholder indicó que la interfaz es clara y fácil de entender, destacando que el uso de imágenes facilita la identificación de los productos.<br><br>

En cuanto a las funcionalidades, confirmó que el sistema cubre adecuadamente sus necesidades actuales, especialmente en el registro de ventas y control de inventario.<br><br>

No se identificaron requerimientos adicionales ni cambios necesarios en esta etapa, ya que el sistema cumple con las expectativas planteadas inicialmente.
